# 5.1 Navigation Menu ADT

The complete Application Display Template is in `copilot-eval-outputs/05-freemarker/5.1-navigation-menu.ftl`.

## ADT Context

The Navigation Menu ADT receives `entries`. Each `nav_item` in that collection is the portlet's navigation model. The template derives these local variables from that model:

- `nav_item_layout` from `nav_item.getLayout()` identifies a page or URL-layout item.
- `nav_item_children` from `nav_item.getChildren()` is the submenu collection.
- `nav_item.getURL()`, `nav_item.getName()`, and `nav_item.isSelected()` supply the link, label, and Liferay-selected state.

`themeDisplay` is normally available in this ADT as common template context, so the template compares `themeDisplay.URLCurrent` against each item URL and uses the current PLID for an instance-safe DOM id. The ADT must still render from `entries`: `nav_items` belongs to the theme navigation context and is not the Navigation Menu portlet's configured menu model.

## portal_normal.ftl Context

`portal_normal.ftl` is a theme template rendered once for the page shell. It has theme/page objects such as `themeDisplay`, the theme-level `nav_items` collection, layout/page information, and theme macros. It does not receive the Navigation Menu portlet's ADT `entries` collection unless the theme builds and passes an equivalent model itself.

Keep portlet-specific markup and behavior in the ADT. Use `portal_normal.ftl` only to load shared theme assets or to place page-shell navigation that is intentionally based on the theme's own `nav_items` context.
