# 4.1 SCSS Token System for White-Label Theming

## File Structure

```text
src/css/
  _tokens.scss
  _theme-airline.scss
  _airlines.scss
  _typography.scss
  _components.scss
  main.scss
```

## `_tokens.scss`

```scss
:root {
  --color-primary: #1b365d;
  --color-secondary: #ffffff;
  --color-accent: #c9a227;
  --font-family-display: "Arial", sans-serif;
  --font-family-body: "Arial", sans-serif;
  --border-radius-card: 0.5rem;
  --spacing-section: 3rem;
}
```

These are Star Alliance defaults. They ensure a usable theme before an airline is chosen and act as fallbacks for a bad or unknown code.

## `_theme-airline.scss`

```scss
@mixin airline-theme(
  $code,
  $primary,
  $secondary,
  $accent,
  $font-display,
  $font-body
) {
  [data-airline="#{$code}"] {
    --color-primary: #{$primary};
    --color-secondary: #{$secondary};
    --color-accent: #{$accent};
    --font-family-display: #{$font-display};
    --font-family-body: #{$font-body};
  }
}
```

Each of the remaining 23 brands is one mixin invocation. Components consume tokens only, so they need no airline-specific overrides.

```scss
  margin-left: 0;

  text-align: right;

```

Prefer CSS logical properties such as `border-inline-start` and `padding-inline` in new components. The explicit RTL overrides above cover an existing left/right component safely under its airline root.

## `portal_normal.ftl`

Set the attribute on `<html>` so every component inherits the selected token values. A theme setting is the stable default; a URL parameter can deliberately override it for previews or deep links.

```ftl
<#assign configuredAirline = theme_settings["airline-code"]!"STAR" />
<#assign requestedAirline = request.getParameter("airline")!"" />
<#assign airlineCode = (requestedAirline?has_content)?then(requestedAirline, configuredAirline)?upper_case />

<html ${languageUtil.get(locale, "lang")} dir="ltr" data-airline="${htmlUtil.escapeAttribute(airlineCode)}">
```

The theme setting is configured in `liferay-look-and-feel.xml` and available as `theme_settings` in a theme template. `request` is available in `portal_normal.ftl`; validate or whitelist URL codes before using them in production.

For a switch during a session, update `document.documentElement.dataset.airline` from the theme-switcher module. The compiled selectors match immediately, so CSS variables cascade to every component without a page reload. Persist the selected code in `sessionStorage`, then restore it before portlet initialization on subsequent Liferay SPA navigations.

```js
function applyAirlineCode(code) {
  document.documentElement.dataset.airline = code.toUpperCase();
  sessionStorage.setItem("airline-code", code.toUpperCase());
}
```
