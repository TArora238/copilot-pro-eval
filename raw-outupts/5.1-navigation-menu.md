The complete Application Display Template is in `copilot-eval-outputs/05-freemarker/5.1-navigation-menu.ftl`.

## ADT Context

The Navigation Menu ADT receives `entries`. Each `nav_item` in that collection is the portlet's navigation model. The template derives these local variables from that model:

- `nav_item_layout` from `nav_item.getLayout()` identifies a page or URL-layout item.
- `nav_item_children` from `nav_item.getChildren()` is the submenu collection.
- `nav_item.getURL()`, `nav_item.getName()`, and `nav_item.isSelected()` supply the link, label, and Liferay-selected state.

An ADT is rendered in portlet scope, where `themeDisplay` is not guaranteed to be injected as a top-level FreeMarker variable. The template retrieves it from the guaranteed portlet request attribute instead:

```ftl
<#assign theme_display=renderRequest.getAttribute("THEME_DISPLAY")! />
<#assign current_url=(theme_display.getURLCurrent())!"" />
```

The parentheses are important: `themeDisplay.URLCurrent!""` dereferences `themeDisplay` before the default operator can apply. `(theme_display.getURLCurrent())!""` safely defaults the whole property expression when the request lacks `THEME_DISPLAY`, while `nav_item.isSelected()` still supplies Liferay's selected state. The DOM id now uses `renderResponse.getNamespace()`, which is unique to the portlet instance and does not depend on `ThemeDisplay`.

The ADT must still render from `entries`: `nav_items` belongs to the theme navigation context and is not the Navigation Menu portlet's configured menu model.

## portal_normal.ftl Context

`portal_normal.ftl` is a theme template rendered once for the page shell. It normally receives `themeDisplay` directly, plus the theme-level `nav_items` collection, layout/page information, and theme macros. It does not receive the Navigation Menu portlet's ADT `entries` collection unless the theme builds and passes an equivalent model itself.

Keep portlet-specific markup and behavior in the ADT. Use `portal_normal.ftl` only to load shared theme assets or to place page-shell navigation that is intentionally based on the theme's own `nav_items` context.
