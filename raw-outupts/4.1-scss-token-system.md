## `_theme-airline.scss`

```scss
@mixin airline-theme(
  $code,
  $primary,
  $secondary,
  $accent,
  $font-display,
  $font-body
) {
  [data-airline="#{$code}"] {
    --color-primary: #{$primary};
    --color-secondary: #{$secondary};
    --color-accent: #{$accent};
    --font-family-display: #{$font-display};
    --font-family-body: #{$font-body};
  }
}
```

## `portal_normal.ftl`

Set the attribute on `<html>` so every component inherits the selected token values. A theme setting is the stable default; a URL parameter can deliberately override it for previews or deep links.

```ftl
<#assign configuredAirline = theme_settings["airline-code"]!"STAR" />
<#assign requestedAirline = request.getParameter("airline")!"" />
<#assign airlineCode = (requestedAirline?has_content)?then(requestedAirline, configuredAirline)?upper_case />
<#assign rtlAirlineCodes = ["EXAMPLE_RTL"] />
<#assign isRtl = rtlAirlineCodes?seq_contains(airlineCode) />

<html ${languageUtil.get(locale, "lang")} dir="${isRtl?then('rtl', 'ltr')}" data-airline="${htmlUtil.escapeAttribute(airlineCode)}">
```

The theme setting is configured in `liferay-look-and-feel.xml` and available as `theme_settings` in a theme template. `request` is available in `portal_normal.ftl`; validate or whitelist URL codes before using them in production. Direction is a locale property, not a brand-color property: Thai is written left-to-right, so `TG` must not be added to `rtlAirlineCodes`.

For a switch during a session, update `document.documentElement.dataset.airline` from the theme-switcher module. The compiled selectors match immediately, so CSS variables cascade to every component without a page reload. Persist the selected code in `sessionStorage`, then restore it before portlet initialization on subsequent Liferay SPA navigations.

```js
function applyAirlineTheme({ code, rtl }) {
  const normalizedCode = code.toUpperCase();

  document.documentElement.dataset.airline = normalizedCode;
  document.documentElement.dir = rtl ? "rtl" : "ltr";
  sessionStorage.setItem("airline-code", normalizedCode);
}
```
